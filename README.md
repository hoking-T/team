## 第一版完整项目

项目位于 [warehouse](warehouse/)；请从[运行说明](warehouse/README.md)开始。包含Java后端、网页、数据库初始化、测试、报告初稿和25张UML图。原有说明及测试文件保留。

初次体验：下载或克隆仓库，打开warehouse文件夹，双击“启动演示.cmd”，等待启动成功后访问 http://127.0.0.1:8080 。需要已安装Java；本版实测JDK25.0.1。

本次为AI辅助基础版本的真实导入，不代表五人已完成全部开发。测试证据为2026-10-20的历史记录，本次上传没有重新运行业务测试。数据库会在本机首次启动时初始化；现有库存数据、机器日志和本机缓存不上传。
